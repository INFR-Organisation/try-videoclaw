This folder is the template.

Everything on try.videoclaw.com is one folder under public/. There is no framework and no build step to learn — if it works when you open the file locally, it works here.

  1. Copy this folder: cp -R public/hello public/my-idea
  2. Edit public/my-idea/index.html. Give it a real <title> and a <meta name="description"> — the homepage listing reads both.
  3. Commit and push. Vercel rebuilds the index and your page is live at /my-idea.

Drop images, video, JSON, whatever alongside the HTML and reference it relatively:

public/my-idea/
  index.html
  clip.mp4      <- <video src="clip.mp4">
  data.json

To preview the whole site locally before pushing:

npm run dev

Delete anything in here freely. Nothing on this domain is depended on by anyone.
